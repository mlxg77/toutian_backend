# 掘金头条后端 - 部署文档

> 适用项目：`toutiao_backend`（FastAPI + SQLAlchemy + Redis）  
> 部署架构：Docker 容器化（后端 + Redis）+ 宿主机原生 MySQL  
> 最后更新：2026-09-06

---

## 一、架构概览

```
┌──────────────── 云服务器 159.75.82.153 ────────────────┐
│                                                         │
│  ┌─────────────┐                                        │
│  │ MySQL 原生   │  ← 已安装，跑在宿主机（不放容器）    │
│  │ :3306       │                                        │
│  └──────▲──────┘                                        │
│         │ host.docker.internal                          │
│  ┌──────┴────────────── Docker ────────────────────┐    │
│  │  news_net (bridge)                              │    │
│  │                                                 │    │
│  │  ┌──────────────┐        ┌──────────────┐       │    │
│  │  │ news_backend │───────►│ news_redis   │       │    │
│  │  │ (FastAPI)    │        │ (Redis 7)    │       │    │
│  │  │ :8000 对外   │        │ :6379 仅内网 │       │    │
│  │  └──────────────┘        └──────────────┘       │    │
│  └──────────────────────────────────────────────────┘    │
│                    ▲                                    │
│                    │ :8000                              │
└────────────────────┼────────────────────────────────────┘
                     ▼
             前端 / 客户端调用
```

**设计决策**：
- **MySQL 不放容器**：数据库里已有真实数据，放容器有丢数据风险，运维也不方便。
- **Redis 放容器**：缓存数据可重建，丢了无影响；容器化便于迁移和管理。
- **后端放容器**：环境一致性、易扩容、易回滚。

## 三、环境变量（`.env`）

| 变量名 | 说明 | 示例值 |
|---|---|---|
| `DATABASE_URL` | SQLAlchemy 异步连接串 | `mysql+aiomysql://root:Root%40123456@host.docker.internal:3306/news_app?charset=utf8mb4` |
| `REDIS_HOST` | Redis 主机 | `redis`（Docker 内）/ `localhost`（本地开发） |
| `REDIS_PORT` | Redis 端口 | `6379` |
| `REDIS_DB` | Redis DB 号 | `0` |
| `REDIS_PASSWORD` | Redis 密码（可选） | 留空 |
| `SQL_ECHO` | 是否打印 SQL | `false` |

> ⚠️ 密码里的 `@` 必须编码为 `%40`，否则 URL 解析失败。  
> 其他特殊字符：`:` → `%3A`、`/` → `%2F`、`#` → `%23`。

## 四、本地开发

```powershell
# 1. 创建虚拟环境
python -m venv .venv
.venv\Scripts\activate

# 2. 装依赖
pip install -r requirements.txt

# 3. 复制环境变量模板
copy .env.example .env
# 编辑 .env：把 REDIS_HOST 改成 localhost，DATABASE_URL 主机改成 localhost

# 4. 启动（本地要装 MySQL + Redis）
uvicorn main:app --reload
```

访问：
- Swagger UI：http://127.0.0.1:8000/docs
- ReDoc：http://127.0.0.1:8000/redoc

## 五、服务器部署（完整版）

### 5.1 前提条件

| 项目 | 要求 |
|---|---|
| 服务器系统 | CentOS 7+ / Ubuntu 20.04+ / Debian 11+ |
| Docker | 20.10+（支持 `docker compose` V2） |
| Git | 任意版本 |
| MySQL | 已在宿主机装好，监听 `0.0.0.0` 或 `127.0.0.1` |
| 网络 | 出网能访问 Docker Hub / 镜像代理 |

### 5.2 在服务器上装 Docker（如未装）

```bash
curl -fsSL https://get.docker.com | sh
systemctl enable --now docker
docker --version
docker compose version
```

### 5.3 配 Docker 镜像加速（国内服务器必做）

```bash
mkdir -p /etc/docker
cat > /etc/docker/daemon.json <<'EOF'
{
  "registry-mirrors": [
    "https://mirror.ccs.tencentyun.com",
    "https://docker.1ms.run",
    "https://docker.xuanyuan.me"
  ]
}
EOF
systemctl daemon-reload
systemctl restart docker
docker info | grep -A 5 "Registry Mirrors"   # 验证
```

### 5.4 拉代码（GitHub 在国内不稳，用镜像）

```bash
# 一次性配 git 全局镜像
git config --global url."https://gitclone.com/github.com/".insteadOf "https://github.com/"

# clone（看起来还是 github.com，实际走镜像）
cd /opt
git clone https://github.com/mlxg77/toutian_backend.git news_backend
cd news_backend
```

如果镜像挂了，换 `https://kkgithub.com/` 或 `https://ghfast.top/` 重试。

### 5.5 创建 `.env`

```bash
cp .env.example .env
vi .env
```

关键配置：
```env
DATABASE_URL=mysql+aiomysql://root:Root%40123456@host.docker.internal:3306/news_app?charset=utf8mb4
REDIS_HOST=redis
REDIS_PORT=6379
SQL_ECHO=false
```

### 5.6 构建并启动

```bash
docker compose up -d --build
```

第一次大约 3~8 分钟（拉 `python:3.11-slim` + pip 装依赖 + 拉 `redis:7-alpine`）。

### 5.7 验证

```bash
# 看状态（两个都 Up 就 OK）
docker compose ps

# 看后端日志（看到 "Uvicorn running" 就成功）
docker compose logs --tail 30 backend

# 本地测试
curl http://localhost:8000/
# 期望：{"message":"Hello World"}
```

### 5.8 开外网访问

**腾讯云安全组**：
1. 控制台 → CVM → 安全组 → 入站规则 → 新增
2. 协议 TCP / 端口 8000 / 来源 0.0.0.0/0 / 允许

**服务器本地防火墙**（如有）：
```bash
firewall-cmd --add-port=8000/tcp --permanent
firewall-cmd --reload
```

**外网测试**：
```bash
curl http://<服务器IP>:8000/
# 浏览器访问 http://<服务器IP>:8000/docs
```

## 八、常见故障排查

### 8.1 容器起不来 / Exited

```bash
docker compose logs backend
```

| 报错 | 原因 | 解决 |
|---|---|---|
| `ModuleNotFoundError` | 依赖没装全 | 检查 requirements.txt，重新 build |
| `ImportError: main` | 启动命令错 | docker-compose.yml 的 CMD 应该是 `main:app` |
| `Bind for 0.0.0.0:8000 failed` | 端口被占 | `ss -tlnp \| grep 8000` 找占用进程 |

### 8.2 连不上 MySQL

```bash
# 检查 MySQL 在监听
ss -tlnp | grep 3306
# 期望看到 0.0.0.0:3306 或 127.0.0.1:3306

# 在容器里测试连通性
docker exec -it news_backend ping host.docker.internal

# 进容器用 Python 手动连
docker exec -it news_backend python -c "
import asyncio, aiomysql
async def test():
    conn = await aiomysql.connect(
        host='host.docker.internal', port=3306,
        user='root', password='Root@123456', db='news_app'
    )
    print('OK')
    conn.close()
asyncio.run(test())
"
```

如果报 `Access denied`：
- 核对 `.env` 密码（注意 `@` 要编码 `%40`）
- 在 MySQL 里确认 `root@%` 用户存在：
  ```sql
  SELECT user, host FROM mysql.user WHERE user='root';
  ```

### 8.3 连不上 Redis

```bash
docker compose ps news_redis
# 看是否 healthy

docker compose logs redis
# 看 Redis 启动日志

docker exec -it news_backend python -c "
import redis.asyncio as redis, asyncio
async def test():
    r = redis.Redis(host='redis', port=6379, decode_responses=True)
    print(await r.ping())
asyncio.run(test())
"
```

### 8.4 外网访问不了 8000

按顺序排查：
1. 容器在跑？`docker compose ps`
2. 本地能访问？`curl http://localhost:8000/`
3. 腾讯云安全组开了 8000？
4. 服务器本地防火墙放行？`firewall-cmd --list-ports`
5. 服务器公网 IP 对吗？`curl ifconfig.me`

### 8.5 时区不对

Dockerfile 已配 `TZ=Asia/Shanghai`。如果还不对：
```bash
docker exec -it news_backend date
# 看容器时间
```

## 九、安全建议

| 项 | 现状 | 建议 |
|---|---|---|
| 数据库密码 | 在 `.env` 里 | ✅ 已做，确保 `.env` 不进 Git |
| Redis 密码 | 未设 | ⚠️ 仅内网访问可不设；对外暴露必须设 |
| 安全组 | 默认全关 | ✅ 只开 8000 / 22 / 80 / 443 |
| HTTPS | 未配 | ⚠️ 生产必配，用 Nginx + Let's Encrypt |
| 镜像漏洞 | 用官方基础镜像 | 定期 `docker compose up -d --build` 重建拉新补丁 |

## 附录 A：完整 `docker-compose.yml`

```yaml
version: "3.9"

services:
  redis:
    image: redis:7-alpine
    container_name: news_redis
    restart: unless-stopped
    expose:
      - "6379"
    volumes:
      - redis_data:/data
    command: redis-server --appendonly yes --maxmemory 128mb --maxmemory-policy allkeys-lru
    networks:
      - news_net
    healthcheck:
      test: ["CMD", "redis-cli", "ping"]
      interval: 10s
      timeout: 3s
      retries: 5

  backend:
    build:
      context: .
      dockerfile: Dockerfile
    container_name: news_backend
    restart: unless-stopped
    ports:
      - "8000:8000"
    env_file:
      - .env
    extra_hosts:
      - "host.docker.internal:host-gateway"
    depends_on:
      redis:
        condition: service_healthy
    networks:
      - news_net

volumes:
  redis_data:

networks:
  news_net:
    driver: bridge
```

## 附录 B：完整 `Dockerfile`

```dockerfile
# 阶段 1：构建
FROM python:3.11-slim AS builder
WORKDIR /build
COPY requirements.txt .
RUN pip install --no-cache-dir --prefix=/install \
    -i https://pypi.tuna.tsinghua.edu.cn/simple \
    --trusted-host pypi.tuna.tsinghua.edu.cn \
    -r requirements.txt

# 阶段 2：运行
FROM python:3.11-slim
ENV TZ=Asia/Shanghai \
    PYTHONDONTWRITEBYTECODE=1 \
    PYTHONUNBUFFERED=1
RUN ln -snf /usr/share/zoneinfo/$TZ /etc/localtime && echo $TZ > /etc/timezone
WORKDIR /app
COPY --from=builder /install /usr/local
COPY . .
EXPOSE 8000
CMD ["uvicorn", "main:app", "--host", "0.0.0.0", "--port", "8000", "--workers", "2"]
```
